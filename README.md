VITMarket is a campus commerce platform designed for VIT students to discover, compare, buy, sell, and locate products available around campus.

✨ Features 🔎 Smart Product Search — Quickly find products across campus. 🏪 Campus Stores — Browse stores and their available products. 📦 Product Discovery — View product details, prices, and availability. 🗺️ Campus Navigation — Find where products and stores are located. 🛍️ Student Marketplace — Buy and sell items within the student community. ❤️ Favorites — Save products for quick access. 📊 Demand Insights — Support smarter product and inventory decisions. 📱 Responsive Design — Designed for both desktop and mobile use. 🖥️ Currently only Windows Version

This repository contains the ready-to-use Windows version of VITMarket.

Running VITMarket Download the VITMarket package. Extract the ZIP file. Open the extracted folder. Run: Start-VITMarket.bat VITMarket will open in your web browser.

Note: The Windows package is intended to be run locally on Windows. GitHub stores the files but does not execute the .bat file.
